USER UPLOAD → MINT NFT FLOW:
────────────────────────────────────────────────────────────────────────────────

1. 📤 User uploads bill image
         ↓
2. 🖼️ PaddleOCR extracts text
         ↓
3. 🔄 Transform to structured data
         ↓
4. 📤 Upload to IPFS (Pinata)
         ├─→ Image IPFS hash
         └─→ Metadata IPFS hash
         ↓
5. 💾 Save locally (outputs/)
         ├─→ _ocr.txt
         ├─→ _result.json
         └─→ _blockchain.json
         ↓
6. 🎨 Backend mints NFT
         ├─→ Uses default wallet (.env)
         ├─→ Calls mintBill() on contract
         └─→ Returns Token ID
         ↓
7. ✅ Status: "NFT已鑄造"


USER INTERACTION → BLOCKCHAIN FLOW:
────────────────────────────────────────────────────────────────────────────────

1. 🔗 User connects MetaMask wallet
         ↓
2. 🌐 Web3.js establishes connection
         ├─→ Check network (Sepolia)
         └─→ Get user address
         ↓
3. 📊 User clicks "查詢提單數據"
         ├─→ Enter Token ID
         ├─→ Call getBillData(tokenId)
         └─→ Display results
         ↓
4. 💰 User clicks "質押融資"
         ├─→ Enter Token ID, financier, amount
         ├─→ Build transaction
         ├─→ MetaMask signs transaction
         ├─→ Submit to Sepolia
         ├─→ Wait for confirmation
         └─→ Show transaction hash + Etherscan link
         ↓
5. 🔓 Financier clicks "釋放所有權"
         ├─→ Switch to financier wallet
         ├─→ Enter Token ID
         ├─→ Call releaseOwnership()
         ├─→ MetaMask signs transaction
         └─→ Bill unlocked
